# TVU Connect sound pack

These WAV files are original synthesized tones generated by
`scripts/generate-notification-sounds.cjs`. They contain no third-party music or
recordings.

- `message-in.wav`: incoming message while the app is visible
- `message-out.wav`: successfully sent message
- `incoming-call.wav`: incoming call ringtone (loop)
- `outgoing-call.wav`: outgoing ringback tone (loop)
- `call-connected.wav`: call connected
- `call-ended.wav`: call ended or failed
- `encounter.wav`: consented nearby encounter
- `friend-request.wav`: friend request
- `match.wav`: successful match
- `study-room.wav`: study-room event
- `success.wav`: general success
- `error.wav`: general error

Files can be replaced with custom sounds while keeping the same names. Keep
sounds short and export as mono PCM WAV for broad browser support.

Custom sounds can play only while the web app is open. When it is closed, Web
Push uses the device/browser notification sound; web notification APIs do not
support attaching a custom audio file.
