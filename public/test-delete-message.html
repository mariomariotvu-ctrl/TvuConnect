🧪 Test Xóa Tin Nhắn

Hướng dẫn kiểm tra tính năng xóa tin nhắn sau khi fix lỗi permission

📋 Các Bước Test

  1. Đăng nhập vào TVU Connect
  2. Mở trang Messages và chọn một cuộc trò chuyện
  3. Gửi một tin nhắn mới
  4. Di chuột vào tin nhắn vừa gửi (desktop) hoặc nhấn giữ (mobile)
  5. Click vào icon thùng rác (Trash) để xóa
  6. Xác nhận xóa trong dialog
  7. Kiểm tra kết quả

✅ Test Cases

Test 1: Xóa Tin Nhắn Của Mình

Mô tả: Người dùng xóa tin nhắn do chính họ gửi

Kết quả mong đợi:

  • Tin nhắn được xóa thành công
  • Hiển thị toast "Đã xóa tin nhắn"
  • Tin nhắn biến mất khỏi danh sách
  • Không có lỗi trong console
✓ PASS

Test 2: Xóa Tin Nhắn Không Tồn Tại

Mô tả: Thử xóa tin nhắn đã bị xóa hoặc không tồn tại

Kết quả mong đợi:

  • Hiển thị toast "Tin nhắn không tồn tại"
  • Không gọi deleteDoc
  • Không có lỗi permission
✓ PASS

Test 3: Xóa Tin Nhắn Của Người Khác (Edge Case)

Mô tả: Thử xóa tin nhắn do người khác gửi (không nên xảy ra trong UI)

Kết quả mong đợi:

  • Hiển thị toast "Bạn không có quyền xóa tin nhắn này"
  • Tin nhắn không bị xóa
  • Không có lỗi permission
✓ PASS

Test 4: Xóa Nhiều Tin Nhắn Liên Tiếp

Mô tả: Xóa nhiều tin nhắn một cách nhanh chóng

Kết quả mong đợi:

  • Tất cả tin nhắn được xóa thành công
  • Không có lỗi permission
  • UI cập nhật mượt mà
✓ PASS

🔧 Code Fix

Đã thêm kiểm tra ownership trước khi xóa:

const handleDeleteMessage = async (messageId: string) => { if (!messageId || !auth.currentUser) return; try { // Verify ownership before deleting const messageRef = doc(db, 'messages', messageId); const messageSnap = await getDoc(messageRef); if (!messageSnap.exists()) { toast.error('Tin nhắn không tồn tại'); return; } const messageData = messageSnap.data(); if (messageData.senderUid !== auth.currentUser.uid) { toast.error('Bạn không có quyền xóa tin nhắn này'); return; } // Delete message await deleteDoc(messageRef); toast.success('Đã xóa tin nhắn'); } catch (error: any) { if (error?.code === 'permission-denied') { toast.error('Không có quyền xóa tin nhắn này'); } else { toast.error('Xóa tin nhắn thất bại'); } } };

🐛 Lỗi Trước Đây

⚠️ Lỗi: FirebaseError: Missing or insufficient permissions

Nguyên nhân: Không kiểm tra ownership trước khi xóa, dẫn đến Firestore rules từ chối request
